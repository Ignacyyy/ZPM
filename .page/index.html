Why ZPM

Less package chaos. More shipping.

ZPM keeps the Linux package toolbox powerful, but makes the everyday workflow feel consistent and fast.

One interface

Use one z* command family instead of switching syntax between apt, dnf and zypper.

Fast search

zsearch checks package options without forcing you to know the provider first.

Open source

MIT licensed and transparent, with source access directly from the command cards below.

Cache control

Clean package leftovers with zclean and keep the system tidy.

Built for daily terminal work.

The UI stays close to what ZPM is: a focused command-line tool for people who want speed without mental overhead.
